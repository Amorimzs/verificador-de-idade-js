# Verificador de Idade 👶🧔👵

Projeto desenvolvido para praticar a manipulação do DOM (Document Object Model), estruturas condicionais estruturadas e lógica de programação em JavaScript puro.

O objetivo do projeto é receber o ano de nascimento e o gênero de um usuário, calcular a idade atualizada com base no sistema do dispositivo e exibir dinamicamente uma mensagem de texto juntamente com a foto correspondente à sua faixa etária.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do formulário e container de resultados.
- **CSS3:** Estilização responsiva e centralização do layout.
- **JavaScript (ES6):** Captura de dados do DOM, validação de inputs, cálculo dinâmico de datas e alteração de atributos de imagem.
